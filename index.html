INSTITUTIONS & POLICY SPACE

What is the society choosing?

Three editable policy packages in a three-dimensional issue space. Values range from −1 to +1. Utility decreases with weighted squared distance from each agent's ideal position [S1].

Election mechanics

Full Borda action space: all six rankings. Approval: all seven nonempty ballots. Abstention is a separate action. Failed ballot access forces abstention after an action is chosen.

Learning and incentives

Learning rates, exploration and neural settings

Behavioral assumptions

Choose fixed, stochastic, tabular or neural decision policies. The learning models use 18 coarse observations [S2]. Multi-agent non-stationarity and coarse observations preclude convergence guarantees. A rule change clears Q tables to avoid reusing incompatible actions.

INFORMATION & ENVIRONMENT

Control when, where and how.

Schedule numerical misinformation, correction, resistance, communication loss, ballot-access changes or true utility shocks. These act only on this synthetic society.

Schedule an event

All target filters are combined with AND. Empty agent IDs means any matching agent. Period controls repeat exposure. End round is exclusive. Misinformation changes beliefs, not underlying utility. Negative signals can reduce perceived utility.

Diffusion & belief dynamics

Simple diffusion needs one distorted group member; threshold diffusion needs a fraction of members [S3]. Memory controls belief inertia. Bounded confidence can block group influence [S4]. Correction timing is configurable, with no empirical effect size baked in [S5].

Scheduled events

Disabling stops future injections. Existing distortion decays; beliefs and learned behavior need not recover immediately.

Comparison contract

Counter-based random draws are keyed by seed, round, agent and mechanism, so unchanged mechanisms use common draws despite branch execution paths. Fresh studies share initial agents within each pair. Snapshot mode conditions on the same current society and varies future random draws only.

Endpoint: mean welfare, belief error, turnout, distortion prevalence and reward across the full run window. Positive B−A is an increase, not automatically an improvement. SD is sample variability across paired differences. One seed cannot estimate variability.

RESEARCH NOTEBOOK / V4.0

A model you can inspect.

POLIS is a synthetic agent-based environment for developing and testing hypotheses. V4 combines conditional forecasting, aggregate-data fitting, independent neural learning and a handbook laboratory. It has no established real-electorate predictive accuracy.

Mechanisms are research-informed design choices. References motivate questions and model families; they do not validate these parameter values or establish predictive accuracy.

Study files and reproducibility

Export study settings for a fresh replay. Export a checkpoint for the realized population, manual groups, tabular Q tables, neural weights/replay and history. Compare fresh generator samples or conditional futures. Round metrics and synthetic-agent tables export as CSV. The experiment export includes the question, full settings, explicit patch, seeds, endpoints and recorded results.

Boundaries

Three alternatives, three issue axes, 12–600 agents, 16 communities, 12 regions, 8 categorical metadata factors, 40 scheduled events. Aggregate-data calibration and held-out evaluation are available in Forecast. No individual voter-data ingestion, real campaign messaging, unrestricted plugins or real geographic map service. Those limits keep the model auditable and fully browser-native.

Refer to the bundled ODD-style model description, experiment protocol, literature notes, validation report and limitations before interpreting results.
