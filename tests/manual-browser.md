# Rechecking the interface

The completed checks are in `docs/verification.md`. For future changes:

1. Serve at a repository subpath and inspect console/resource errors. Verify the initially paused state, Resume, pause, +1/+10, resize and visibility pause.
2. Edit numeric global controls, use **Apply parameters**, and confirm the actual engine population/metrics. Select/checkbox changes are immediate. Reject invalid values and preserve state.
3. Save community/region/metadata drafts, rebuild and inspect realized cohorts. Test overlapping membership, manual group creation/toggling, topology rebuild and agent geography movement.
4. Schedule every event kind, combine filters, test period/coverage/window boundaries, then disable it and inspect residual state. Verify direct reach and secondary distortion are distinct.
5. Switch all ballot rules/tie settings/abstention; inspect Q reset semantics and action counts. Confirm voting-cost/access behavior matches documentation.
6. Run fresh and snapshot studies, multi-value sweeps, cancellation and partial exports; check protocol and result files against settings. One-seed variability must remain labelled unavailable.
7. Export/import settings and full checkpoints; verify exact restoration, malformed-file messages, large URL fallback, clipboard failure and browser-storage denial.
8. Inspect mobile and laptop layouts, focus visibility, keyboard access and reduced-motion behavior. A selector is available for every canvas selection action.
