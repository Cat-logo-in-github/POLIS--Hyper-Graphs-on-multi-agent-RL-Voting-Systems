# Scientific and technical boundaries

POLIS is a bounded, transparent playground, not a complete theory of voting behavior. It is useful for mechanism exploration and reproducible model experiments. An analyst must justify assumptions, assess sensitivity, and validate against appropriate empirical data outside this tool before drawing empirical conclusions.

1. No actual citizens, real geographic boundaries, demographic estimates, voter-file ingestion, political text generation, real campaign optimization or deployment to an external communication service. Community/geography labels and categorical metadata are synthetic.
2. Three alternatives and three fixed issue axes; policy position names are editable but axis names are fixed. Weighted squared utility, trait copying, clipped noise, group confidence and offset dynamics are design choices. No parameter defaults are empirical effect estimates.
3. Resource/metadata values have no automatic political association. Metadata filters select exposure; resource is also a cohort/filter variable. If real outcomes appear correlated with metadata in a toy run, that does not establish a real-world relationship.
4. Communities initially assign exclusive membership; overlapping memberships can be created through the agent editor. Community generator traits do not retroactively overwrite realized agents. Manual groups and agent edits require checkpoints or snapshot-mode studies to be retained.
5. Network affinity and abstract distance are uncalibrated. Pairwise/hypergraph comparisons change membership and degree as well as order. The exclusion parameter is stochastic, not an exact isolation percentage, and additional isolates can arise. Isolation fallback signals differ in scale from normalized group signals. These choices can create structural effects unrelated to a general hypergraph advantage.
6. Distortion transmission includes self in group aggregates. Offsets can sustain each other, so turning injection off need not imply recovery. Corrections reduce the selected offset, not necessarily belief memory. The same-round order of resistance and false-signal events matters. Recovery time is not estimated.
7. Eighteen observation states are generally not Markov sufficient. Independent Q-learners face non-stationarity; there is no convergence, rationality or equilibrium guarantee. Reward maximization is not welfare maximization. Latest nonterminal Q updates wait for the next actual observation. Q values estimate the defined toy rewards.
8. Approval's first-candidate counts are a bookkeeping choice; Borda ballots contain all alternatives and its ballot/conformity reward components are rank-invariant. This is disclosed rather than labelled strategic sophistication. Fixed and learning voters can differ in voluntary abstention as well as adaptation.
9. With abstention disabled, access/turnout restrictions are disabled. With all agents abstaining, no policy is elected, welfare is zero, and regret compares to the best feasible policy. This convention is not a constitutional model.
10. Eight-seed bundled examples and 1–12-seed UI experiments offer exploratory variability, not population inference. No p-values, confidence intervals, power analysis, degree-matched causal identification or novelty claim. Snapshot seeds vary futures of one society, not population composition.
11. No migration, births/deaths, strategic campaign actors, changing issue salience during exposure, coalition bargaining, multiwinner elections, alternative-count editor, arbitrary model scripting, empirical estimation, machine-learned voter profiles, real time units or spatial GIS.
12. Caps: 600 agents, 16 communities, 12 regions, 8 categorical factors, 40 scheduled events, 3,000 round history, 80 agent rewards, 500 ledger entries. Workers keep batch studies off the main thread where supported. No hardware-independent performance guarantee is made. Above 250 agents only the selected group's connections are drawn to preserve legibility.
13. Study links share configuration, not state. Checkpoints can be large (import cap 8 MB). Browser storage is optional and may fail; checkpoints still download and remain in session memory. A reload without a saved file/storage loses in-memory edits. Existing V1 JSON is intentionally incompatible.
14. This is an extension of standalone V1. The named external repository was not locally supplied or inspected. No original research code, bibliography or results were reused. GitHub Pages deployment must be enabled by the owner and was not publicly executed here.
