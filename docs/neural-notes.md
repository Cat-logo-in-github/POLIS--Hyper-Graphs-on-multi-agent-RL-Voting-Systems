# Neural and behavioral models in V4

These are alternative mechanisms for a synthetic society. Fitting a neural value function to a simulated reward does not fit human psychology, validate an election forecast or establish the optimal social institution. Compare the same society, seed list, horizon and reward under sincere, random, logit, tabular-Q and neural-Q assumptions.

## Independent neural Q-learning

Every neural actor has its own fully connected network, target network and replay buffer. Parameters are not shared. The input is the same **18 local observations** used by the tabular baseline, encoded one-hot: perceived favorite × group-signal favorite × utility-gap bin. There is one tanh hidden layer (default width 8), followed by eight linear outputs. Only legal action outputs enter selection or the bootstrap. The default network has 224 trainable parameters, plus its frozen target copy. This small MLP is a transparent neural-Q baseline, not an Atari-scale architecture or recurrent model.

The learner receives its local coarse observation and its defined scalar reward. It does not receive another agent's hidden utility, a future winner, or ground-truth population labels as input. Outcome utility still enters the environment's reward, exactly as in the tabular model. The coarse observation need not be Markov; neither learner has a convergence guarantee in this changing multi-agent environment.

Action selection is epsilon-greedy, with the existing keyed exploration schedule. Nonterminal transitions are completed only at the next **actual** observation; terminal updates have no bootstrap. The network target for a completed tuple is

```
y = reward                                      if terminal
y = reward + gamma × max_legal Q_target(next)    otherwise
```

The tuple is appended to a bounded recent buffer. Each update minibatch contains the newest tuple and uniformly drawn replay tuples with replacement; the size is min(requested batch, current buffer size). This intentional newest-plus-replay scheme differs from a completely uniform batch. Targets are computed from the frozen network. Backpropagation minimizes the mean Huber TD loss (quadratic to absolute TD error 1, linear beyond it). The mean gradient has global norm clipped to 5, then SGD applies the configured neural rate. Weights/biases are bounded to [-10,10] for numerical containment. Every configured number of **completed agent updates**, the online weights are copied to that agent's target. No optimizer momentum, Double-DQN, prioritized replay, fingerprints or importance weights are implemented.

The inspector reports the actual current legal-action predictions, target predictions, architecture, latest loss, buffer size, update count and target-copy count. `lastUpdate` also records before/after prediction for the newest tuple, target, TD error, real minibatch Huber loss, gradient norm/scale, replay size and target-copy event. An update can affect predictions at other observations through shared network weights. The tabular Q matrix is kept separate rather than overwritten with neural estimates.

Changing ballot semantics or hidden width resets the incompatible neural model and replay. Ordinary topology/aggregation edits preserve it. Switching between tabular and neural learning clears pending transitions and retains their separate compatible learned representations. A smaller replay capacity truncates the oldest tuples. Continuing/finite-horizon semantics are the same as the tabular engine; finite information resets preserve learned networks.

Full checkpoints include online/target weights, replay tuples, counters and pending transitions. Historical frames record actual network state too, within the existing bounded-retention limits; inspecting a frame does not train a model or consume randomness. Old V2/V3 checkpoints migrate to V4. Their missing initial belief anchor becomes their restored belief, since an earlier prior cannot be reconstructed. Zero-default anchoring itself adds no continuation change; earlier corrections to V2 normalization, rewards and terminal semantics still apply when a V2 checkpoint migrates.

## Logit baseline and behavioral controls

**Logit decisions** score each legal ballot by perceived ballot utility minus participation cost, then sample probabilities proportional to exp(score / temperature). No strategic equilibrium is solved and the score does not predict whether the voter's ballot will be pivotal. At temperature zero, selection is uniform over maximizing scores; higher temperature approaches more diffuse decisions. Logit actors do not train Q tables or networks. This is a reduced-form stochastic decision assumption, not a quantal response equilibrium solver.

The information pipeline first calculates its ordinary memory/evidence/social candidate belief. **Confirmation bias** then attenuates changes that weaken the current favorite: a downward change in that favorite or an upward change in another policy is multiplied by (1-bias). Other changes pass through. **Stubbornness** blends this result with the actor's fixed initial belief anchor: `(1-stubbornness) × result + stubbornness × initialBelief`. Both controls default to zero. Their zero path returns the original candidate directly, preserving existing numerical transitions and keyed randomness. A value of one has a strong modeled effect and should be treated as a sensitivity bound, not an estimated human trait. Traces expose raw candidate, anchor and applied coefficients. These are additional assumptions on top of the engine's normalization, bounded confidence and spatial utilities; their units are not interchangeable.

The experimental implementation is new code applying these method families. It is not a perfect simulation of the cited theories or real voters. An institution's best observed synthetic welfare under one learner can change with reward, horizon, priors, action representation, randomness and evaluation window. External calibration, held-out validation and model comparison remain necessary before treating model outputs as empirical forecasts.

## Executed numerical verification

The neural-specific suite contains 15 passed tests covering actual gradient descent, frozen/terminal targets, minibatch determinism, independent models, exact checkpoint futures in both task modes, historical network independence, malformed networks/replay/records, resets, logit probabilities and neutral behavioral controls. An additional comparison against the preserved V3 engine ran four scenarios for 40 rounds each; every round metric and final tabular Q value matched exactly with the new behavioral controls at zero. A local 72-agent, 100-round neural smoke run completed with 99 updates for each continuing-task actor, a full 64-tuple recent buffer and three target copies at the default interval. These checks demonstrate execution/reproducibility, not voter forecast accuracy or convergence.
