# Changelog

## V4.0 — 20 October 2026

- Added actual independent neural Q-learning with bounded replay/target networks, numerical loss/updates, complete checkpoint state and neutral behavioral controls; added logit decisions.
- Added conditional seeded forecast distributions, parameter assumptions, aggregate observation imports, chronological fit/holdout evaluation with disjoint seeds, proper-score summaries and naive baselines.
- Added one representative runnable/visualized experiment for each handbook chapter, with exact coverage/caps and editable data.
- Expanded rule studies to five policies, custom value weights, sample-mean Pareto comparisons and exact trained candidate inspection.
- Added guided/researcher disclosures, contextual explanations, revised navigation and source mappings.
- Preserved original studio, interventions, cohorts, replay, matching and robust-search behavior. No perfect/validated electorate or universal-optimum claim.


## V3.0 — 20 October 2026

This release extends the delivered V2.0 browser source. Its version follows the user's request even though the revised mission PDF is titled “2.0”. The public Python course-project repository was reviewed as a separate reference, not merged into the static application.

### Scenario and rule evaluation

- Added a voting-rule benchmark across three rules and sincere/random/independent-Q policies, using matched fresh populations, explicit objectives and final evaluation windows.
- Added hypothetical public-budget, unequal-access and information-shock scenarios with per-seed outcomes, community welfare floors, competing metrics and exports.
- Added a scenario guide that distinguishes best observed finite candidates from a real-world optimum.

### Scientific corrections

- Normalized every group signal and isolated/confidence-rejected fallback consistently.
- Separated interaction topology from aggregation; added linear and no-aggregation controls alongside nonlinear, plurality and consensus-threshold mechanisms.
- Excluded the receiving agent from signed-distortion transmission source counts and means.
- Replaced V2 action-invariant full-Borda ballot/conformity terms with normalized 2/1/0 rank weights; approval now uses mean selected-policy alignment.
- Distinguished continuing-task bootstrapping from finite-horizon terminal updates and explicit information-state reset.
- Used one cached social communication pass per round, preserving actual received information for observation/conformity and preventing a hidden second communication budget.
- Counted direct exposure only for nonzero applied false doses; zero-dose attempts remain traceable.

### Controlled structure and model inspection

- Added no communication, independently generated pairs, hyperedges, exact source-group clique projection, degree-preserving randomized null and periodic dynamic swaps.
- Preserved parallel projected pairs and active/inactive incidence strata during randomized swaps.
- Added grouping by community, ideal similarity, recent action or random affinity, plus manual-only grouping.
- Added ordered membership/communication budgets, actual structure/exposure diagnostics and limitations for unattainable matching goals.
- Added manual group member changes, toggles, deletion, selection tools and bounded topology undo/redo.
- Added real reward decomposition, conditional action-invariance diagnostics and actual state/action/reward/target/Q/TD-error traces.

### Counterfactuals, experiments and exports

- Preserved independent full checkpoint branches and explicit future-seed override semantics.
- Added bounded actual live history and synchronized A/B replay frames, with retained/omitted rounds and event-focused recording.
- Added named local branch saves, divergence inspection and continuation from full final treatment state.
- Added two-axis measured sensitivity surfaces, completed sample counts, descriptive SD/quantiles, raw exports and cell loading/inspection.
- Added measured configuration differences, structural matching contracts and concrete confounder warnings.
- Added synthetic communication-failure contrasts and a module API for explicitly defined metric recovery.
- Added bounded exhaustive existing-ballot replacement analysis with exact-minimum and search-limit labels.
- Added self-contained HTML report generation and replayable JSON protocols.

### Research and delivery

- Verified 14 primary-source mappings, including HYGMA, HyperComm, Voting-Based MARL, complex contagion, bounded confidence, ODD, null models, election fragility and sensitivity analysis.
- Recorded actual access levels and non-reproduction boundaries rather than claiming inaccessible full papers were read.
- Corrected deployment-path instructions and public-source provenance.
- Retained local browser JavaScript, relative paths, static assets and GitHub Pages deployment without runtime dependencies.

### Deferred and bounded

A learned adaptive adversary/defense, empirical calibration, neural MARL algorithms and global sensitivity decomposition are not implemented. Historical frames, traces, seed grids and ballot search are deliberately bounded. V2 files migrate into V3 semantics; their continuation is not guaranteed numerically identical. See limitations.md and experiments.md.

Test counts, browser observations and archive verification are recorded in verification.md, without treating this feature list as test evidence.

## V2.0 — previous delivered release

Added editable synthetic communities, geographies and metadata; targeted scheduled interventions; independent tabular Q-learning; plurality, approval and Borda; checkpoint and repeated-seed comparisons; CSV/JSON exports and seven initial research references. Its original automated baseline contained 49 passing tests before V3 modifications. V3 corrects scientific assumptions that those tests did not isolate.
