# V2.0 changes

- Six coordinated workspaces: Lab, Society, Policies, Interventions, Experiments, Research.
- Population expanded to 12–600. Explicit parameter commit, bounded numeric inputs and errors.
- Editable community generators with issue ideals, salience, dispersion, relative population, trust, susceptibility, participation, resource, media and home geography.
- Editable abstract geographies with ballot access, population weights and policy-specific real benefits.
- Custom categorical metadata, realized agent editing, overlapping communities, manual hyperedges, affinity/geographic topology and dynamic rewiring.
- Editable three-axis policy packages; all six Borda rankings, seven approval masks, abstention, seeded ties, access failures and voting costs.
- Scheduled false signals, correction, resistance, blackout, ballot-access and utility shocks. Combined filters, signed doses, repetition, coverage and explicit active/end states.
- Persistent distortion and beliefs, simple versus group-threshold secondary transmission, bounded confidence, decay and memory.
- Independent 18-state Q tables, fair seeded tie selection, pending transitions bootstrapped at the next actual observation, explicit terminal updates and rule-change resets.
- Paired studies and numerical sweeps in a worker, common keyed random draws, fresh versus conditional-future studies, variability reporting and cancellation.
- Community, region, metadata and resource cohorts with true preferences and actual ballot support; exports of synthetic agents, round metrics, full checkpoints and study protocols/results.
- Research citations tied to implemented mechanisms, detailed ODD-style model description, reproducible examples and expanded test suite.

V2 is a richer bounded environment, not an assertion that all political behavior can be modeled or predicted.
